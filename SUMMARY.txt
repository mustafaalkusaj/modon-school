                            🔴 المشاكل المكتشفة
================================================================================

1. ❌ عدم وجود Server-side Caching
   - جميع API responses مع: "Cache-Control": "private, no-store, max-age=0"
   - يعني البيانات تُجلب من جديد في كل مرة
   - التأثير: بطء فظيع في كل مكان

2. ❌ Client-side Cache قصير جداً
   - استخدام sessionStorage مع TTL = 20 ثانية فقط
   - بعد 20 ثانية يفقد الـ cache ويُعاد جلب البيانات
   - التأثير: عند الرجوع للصفحة يتأخر التحميل

3. ❌ Multiple Concurrent API Calls
   - صفحة واحدة تطلب:
     • /api/web/students/list
     • /api/web/students/meta
     • /api/web/class-fees
   - كل واحد request منفصل!
   - التأثير: Network congestion و slow page load

4. ❌ عدم وجود Request Deduplication
   - نفس الـ request يُرسل عدة مرات بدون دمج
   - التأثير: wasted resources

5. ❌ عدم وجود Real-time Updates
   - تضطر لتحديث الصفحة لرؤية البيانات الجديدة
   - التأثير: سوء UX وشعور بـ lag
