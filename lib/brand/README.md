# Brand Folder

هذا المجلد يجمع كل ما يخص هوية مشروع الويب في مكان واحد.

## الملفات

- `name.ts`
  اسم المشروع العربي والإنكليزي والعناوين الفرعية.
- `logo.ts`
  اللوجو الافتراضي وplaceholder الخاص به.
- `colors.ts`
  ألوان المشروع الافتراضية، ألوان الثيمات، وألوان الواجهة light/dark.
- `palette.ts`
  دوال توليد الألوان، مزجها، تخزين branding المدرسة، واستخراج palette من الشعار.
- `themes.ts`
  مكتبة الثيمات الجاهزة المقترحة للمدارس.
- `shared.ts`
  أدوات داخلية مشتركة.
- `index.ts`
  نقطة التصدير المركزية للهوية.

## التوافق

الملفات القديمة التالية ما زالت موجودة فقط كـ wrappers للتوافق:

- `lib/branding.ts`
- `lib/brand-palette.ts`
- `lib/brand-themes.ts`
