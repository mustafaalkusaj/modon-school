# Interaction States

## Global Shell

- AppSidebar: default, hover item, active item, mobile closed, mobile open, super-admin school selector loading, selector with chosen school, selector invalid state
- AppShellTopbar: default, with actions, mobile compact, fixed state
- ProfileMenu: closed, open, theme switch active, language toggle, sign-out action

## Inputs And Buttons

- Inputs: default, hover, focus, filled, disabled, validation error, async loading context
- Password field: hidden, revealed
- Primary buttons: default, hover, disabled, loading
- Secondary and ghost buttons: default, hover, disabled
- Theme mode toggle: floating, inline, active option, inactive option

## Feedback

- Toast: success, error, warning, info, auto-dismiss progress, dismissing
- School scope banner: selected school, no school selected, invalid school id, loading schools
- Empty states: generic no-data, blocked-by-scope, no operational data, no search results
- Skeletons: dashboard, students page, payments page, table row, stat card

## Tables And Data Workspaces

- Table row: default, hover, selected, action menu open
- Filters: default, filtered, reset, disabled while loading
- Pagination: default, current page, disabled prev/next, gap ellipsis

## Overlay Families

- Confirm dialog: closed, open, danger tone, primary tone, busy
- Modal forms: create, edit, validation error, saving, success, server error
- Detail panels/drawers: closed, open, loading detail, empty detail, delete pending

## Screen-Specific States

- Dashboard: loading, scope blocked, no operational data, data ready, classes modal open, fee modal open
- Students: active tab, transferred tab, suspended tab, deleted tab, import preview, account card revealed password, delete confirm
- Teachers: import modal, account card modal, reset password pending, teacher form errors
- Attendance: unrecorded-only filter, save pending, history loaded
- Payments: student detail open, payment modal search dropdown open, archive detail open, delete payment confirm
- Expenses: invoices tab, types tab, type form open, expense form open, delete pending
- Salaries: section switching, pay salary calculation modes, archive confirm, export modal, print modal, manager modals
- Monitoring: messages tab, homework tab, detail edit mode, delete confirm
- Fee Notifications: composer targeting all students/branch/class-section/specific students, sending, history detail modal
- Super Admin: tab switching, hidden tabs via infrastructure flags, diagnostics banner, spotlight filter applied, school/user modal open, destructive dialog open
